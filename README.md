# Transliteration Accuracy Testing

Run Singlish → Sinhala automated tests using Playwright.

Requirements
- Node.js 18+

Install

```bash
npm install
npx playwright install
```

Run tests

```bash
npx playwright test
```

Results
- Excel file: `results/neg_test_results.xlsx`
- Screenshots: `results/screenshots/`
# IT3040-Transliteration-Accuracy-Testing
This repository evaluates the accuracy of the Pixelssuite Chat Translator in converting Singlish inputs into Sinhala outputs.  Includes 50 negative test cases across 24 input types, automated scripts, and Excel reporting.
